Data deletion

Last updated: 2026-11-24

AI Content Studio keeps data only on its owner's computer (see the Privacy Policy).

Revoke the tool's access

  • Google / YouTube: Google Account: Third-party connections, select AI Content Studio, remove access.
  • Other platforms: remove the app in that platform's connected-apps settings (listed on Platform notes once connected).

Delete stored data

The owner deletes the channel's token from Windows Credential Manager and the channel's local operating records. Revoking access alone already stops all further access.

Request deletion

If you believe the tool holds data about you, open an issue with the contact link below. The tool accesses only its owner's accounts, so it is not expected to hold anyone else's data; any such data found is deleted.
