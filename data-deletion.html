Data deletion

Last updated: 2026-11-24

AI Content Studio keeps data only on its owner's computer (see the Privacy Policy). It accesses only the owner's own accounts, so it is not expected to hold data about anyone else.

Request deletion

If you believe the tool holds data about you, or you want data the tool obtained from your account deleted, contact us: E-mail: insidethebite.tv@gmail.com (preferred), or open an issue in this repository. State which platform and account it concerns. The request is answered and the data deleted without undue delay, and you are told when it is done (or, if nothing is found, that no data was held).

Revoke the tool's access

  • Google / YouTube: Google Account, Security, Third-party connections: remove AI Content Studio.
  • Facebook and Instagram: Facebook Settings, Apps and websites (or Business Integrations): remove the app.
  • Threads: Threads settings, Account, Website permissions: remove the app.
  • Pinterest: Settings, Security and logins (or Apps): revoke access for Inside the Bite Content Studio.
  • Dailymotion: the owner deletes the private API key in Dailymotion Studio.

Revoking access stops all further access immediately.

Delete stored data

The owner deletes the account's token or key from the Windows Credential Manager and the account's local operating records. After that the tool holds no data for that account.
