Privacy Policy

Last updated: 2026-11-24

AI Content Studio ("the tool", also registered on Pinterest as "Inside the Bite Content Studio") is a private tool used only by its owner for the owner's own brand accounts (see Home). The only user whose data it accesses is the owner. It does not collect information from viewers, followers or any other person, and it does not use cookies or collect log-in passwords.

1. Platforms and permissions

The tool connects only through each platform's official API and only to the owner's own accounts. The exact permissions per platform and whether the platform is connected today are listed on Platform notes. In short:

  • Google / YouTube: OAuth scope youtube.force-ssl.
  • Meta (Facebook Pages, Instagram, Threads): pages_show_list, pages_read_engagement, pages_manage_posts, instagram_basic, instagram_content_publish, threads_basic, threads_content_publish. No messaging, comments, ads or insights permissions are requested.
  • Pinterest: user_accounts:read, boards:read, pins:read, pins:write.
  • Dailymotion: the owner's private API key with scope video.manage.

2. What data the tool processes

  • Identity of the owner's own account: account or page ID, name or username. Used only to confirm that the authorized account is exactly the intended brand account before any write; a different account stops the tool.
  • The owner's own posts: IDs, titles, publish or schedule time, processing and publish status, public link. Used to confirm results and to avoid duplicate posts.
  • Platform limits: the account's remaining publishing quota where the platform reports it.
  • Pinterest: the names and IDs of the owner's own boards (to choose where a Pin goes) and the IDs and status of Pins the tool created.

The tool does not request or process contacts, private messages, comments, followers' data, location, payment information, or any other person's account.

3. How the data is used

Only to operate the owner's own accounts: upload, schedule, publish and verify the owner's own content, prevent duplicates, and stay within the platform's limits. It is not used for advertising, profiling, selling, or any other purpose.

4. Storage and protection

  • Access tokens and API keys are stored only on the owner's own computer in the Windows Credential Manager. They are never written to source code, repositories, logs or shared documents, and they are never shown on screen.
  • The tool keeps local operating records on the owner's computer: verified account IDs, the owner's own post IDs, times and status, and API call counts. Pinterest data is fetched from the API when needed; the tool stores only the IDs and status of the Pins it created.
  • The tool has no server of its own and no database outside the owner's computer.
  • Some APIs (for example Instagram and Threads) accept media only from a public web address. If that is needed, a temporary copy of the owner's own video or image may be placed in temporary storage and deleted after it is published. This option is switched off at present.

5. Sharing

Data obtained from a platform is not sold, rented or transferred to anyone. It is only sent back to the same platform as part of the owner's own posts.

6. AI services

The tool has no code path that sends data received from platform APIs (account identity, post lists, publish status, Pinterest board and Pin data) to an AI service, and that data is not used to develop, improve or train any AI or machine-learning model. The tool does not read comments, messages, followers or analytics at all.

The owner does use AI services for the owner's own material: to help write or translate titles, descriptions and subtitles, and to review the owner's own rendered videos before upload. The owner may also use AI coding assistants to maintain the tool on the owner's computer; such an assistant can see local files of the project, which may include the status of the owner's own posts (never tokens or keys, which are only in the Windows Credential Manager). This concerns only the owner's own accounts, never another person's data.

7. Retention

Tokens and keys are kept until the owner revokes access or removes the account from the tool. Local operating records are kept while the owner operates the account and are deleted by the owner when no longer needed. Pinterest data is not kept longer than needed to operate the owner's Pins.

8. Revoking access and deleting data

Access can be revoked at any time in each platform's connected-apps settings, and all locally stored data can be deleted. Steps and how to request deletion: Data deletion.

9. Platform rules

Use of each platform follows that platform's own terms and developer policies, including the Google API Services User Data Policy (with its Limited Use requirements) for data received from Google APIs, the YouTube API Services Terms, Meta Platform Terms, Pinterest Developer Guidelines and the Dailymotion terms of use.

10. Children

The tool is not directed to children and is not used by anyone other than its adult owner.

11. Changes and contact

Changes are published on this page with a new date. Contact: E-mail: insidethebite.tv@gmail.com (preferred), or open an issue in this repository.
